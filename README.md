# VStaff — Built to Earn

VStaff is a technology-driven delivery platform that connects delivery partners with delivery opportunities.

The website is built using React and Vite and provides information about VStaff, delivery partner opportunities, FAQs, rider stories, partner information, and the VStaff mobile app.

## 🚀 Tech Stack

- React 18
- Vite
- JavaScript
- HTML5
- CSS3

## ✨ Features

- Responsive VStaff website
- Home section
- About VStaff section
- Delivery partner information
- Partner information
- VStaff App download
- Contact and social media links
- Responsive footer
- Mobile-friendly design
